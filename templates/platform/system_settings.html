Encryption key help
The SMTP password is encrypted with the server variable AWSUM_SYSTEM_SETTINGS_ENCRYPTION_KEY, read from the process environment or the server-only .env file (excluded from Git). Run py tools\init_encryption_key.py once on the server to create it; the key is never displayed and an existing key is never overwritten. No restart is needed. Back it up separately from the database: without it, saved passwords cannot be decrypted, and a new key must never replace the key of a database that already holds an encrypted password.
